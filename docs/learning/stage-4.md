# Этап 4: автоисправление и режим учителя

## Что сделано

1. **Автоисправление.** Под отчётом панель «Исправить автоматически»: галочки по правилам, которые программа умеет исправлять безопасно. Это поля и размер листа, шрифт и размер, цвет, интервалы, красная строка, выравнивание, правый отступ, отступ пробелами, пустые абзацы и их серии, разрывы страниц перед частями, двойные пробелы, тире, пробелы в скобках и по краям, диапазоны чисел. Кнопка скачивает новый файл «…_исправлено.docx» и сразу проверяет его: отчёт показывает, что исправлено автоматически и что осталось поправить руками.
2. **Режим учителя.** Несколько файлов сразу → таблица: файл, оценка, ошибки, замечания, три главные проблемы. Сортировка по столбцам, экспорт в CSV для Excel, по кнопке — полный отчёт по работе.
3. **Обмен с Web Worker** переделан на «запрос → ответ» с номерами: проверок может быть несколько одновременно, а исправление — ещё один вид запроса.

## Почему так

- **Исходный файл никогда не меняется.** Исправитель получает копию байтов и собирает новый архив. Все части, кроме `word/document.xml`, переносятся байт в байт; тест это проверяет.
- **Порядок свойств по схеме.** Word ожидает свойства абзаца в строгом порядке (`w:spacing` раньше `w:jc` и т. д.). Если вставить свойство «куда-нибудь», Word откроет файл с ошибкой. Поэтому `ensureChild` вставляет новое свойство перед первым соседом, который по схеме идёт позже.
- **Сверка абзацев.** Перед правкой исправитель обходит XML так же, как читатель, и сравнивает число абзацев. Если не совпало, он ничего не трогает: лучше не исправить, чем испортить.
- **Титульный лист не трогаем** (RULES-SCHOOL, раздел 5): там пустые строки иногда держат вёрстку, и это лишь «замечания».
- **TY-02 исправляется частично:** лишний пробел перед знаком убрать легко, а куда ставить пробел «после», программа надёжно не знает.
- **Круговой тест** на прошлой работе повторяет эксперимент из RULES-SCHOOL: после исправления в тексте нет ни серий пустых абзацев, ни частей без разрыва страницы, а текст абзацев не изменился.

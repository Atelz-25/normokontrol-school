# Чек-лист публикации

Перед тем как показывать сайт (защита, одноклассники, учитель).

## Код и проверки

- [ ] `npm run check` зелёный (lint, форматирование, типы, тесты с покрытием ≥ 80 %, сборка).
- [ ] `npm run test:e2e` зелёный локально (или задание `e2e` в CI).
- [ ] Тест по личному файлу прошёл локально (`fixtures/real/sample-v2.docx` есть только на твоём компьютере).
- [ ] `npm run docs:rules` не меняет `docs/RULES.md` (каталог совпадает с кодом).
- [ ] `npm run fixtures` не меняет файлы в `fixtures/` (фикстуры совпадают с описанием).

## Приватность

- [ ] В git нет `.docx` из `fixtures/real/`: `git ls-files fixtures/real` показывает только `.expected.json`.
- [ ] В репозитории нет настоящих имён, названий школ, текстов сообщений учителя (поиск по фамилиям перед пушем).
- [ ] В собранной странице есть CSP `connect-src 'none'` (e2e-тест «приватность»).
- [ ] DevTools → Network: при проверке файла нет запросов (руками, один раз).

## Сайт

- [ ] CI и «Deploy to GitHub Pages» зелёные после пуша.
- [ ] https://atelz-25.github.io/normokontrol-school/ открывается, профиль «Наша школа» выбран.
- [ ] Образцовая работа (`fixtures/good/model-note.docx`) даёт «Замечаний нет» и 100 из 100.
- [ ] Прошлая работа даёт те же замечания, что в эталоне (PR-06, PR-10, PB-01, PG-02…).
- [ ] Работает без сети: открыть сайт, выключить интернет, обновить страницу, проверить файл.
- [ ] Телефон: отчёт читается, «Показать в тексте» работает.

## Документы

- [ ] README: статус, возможности, быстрый старт, зависимости.
- [ ] `docs/learning/stage-0…5.md` прочитаны: могу ответить на вопросы для самопроверки.
- [ ] `docs/LIMITATIONS.md` и `docs/EVALUATION.md` актуальны: честно говорю, где программа может ошибаться.
- [ ] Открытые вопросы к учителю (`docs/school-guidelines.md`, раздел 6) — что уже подтверждено, что нет.

# Дизайн «Нормоконтроля»

Коротко о том, откуда взялся внешний вид и по каким правилам он сделан. Все числа (цвета, шрифты, размеры, длительности) живут в одном файле — `src/ui/tokens.css`. Снимки всех состояний: `npm run design:shots` → `docs/design/`.

## Образ

Сайт — рабочий стол корректора. Главный предмет на нём — лист A4 с полями, на котором красным карандашом отмечены ошибки. Отсюда всё остальное:

- **Зона загрузки** — контур листа 210 × 297 с размеченными полями, как на чертеже: тонкие размерные линии с засечками и подписи «30 мм». Числа берутся из выбранных требований (правила PG-02…PG-05), поэтому при смене профиля лист меняется.
- **Отчёт** — корректурный лист: слева на полях номер правила и знак серьёзности (полоса цвета карандаша), справа текст замечания. Блоки разделены линиями, а не коробками.
- **«Из-за чего снижали баллы»** — поля тетради: номер правила слева от красной линии, как пометка учителя.
- **Текст работы** — лист с красной линией полей, номера абзацев на полях.
- **Карта документа** — узкая полоса рядом с отчётом: штрих на каждый абзац (длина — по длине абзаца), пропуски на месте пустых абзацев, засечки на полях там, где замечания. Видно, где в работе «дырки» и где скопились ошибки.
- **Ошибка чтения файла** — лист перечёркнут красным карандашом. **Замечаний нет** — чистый листок из тех же линий.

Ориентиры: школьная тетрадь, издательская корректура, линейка с миллиметрами, типографские знаки. Сайт должен выглядеть как инструмент, а не как реклама.

## Цвет

| Токен | Светлая | Тёмная | Смысл |
|---|---|---|---|
| `--desk` | `#ebe5d9` | `#1b1916` | стол, фон страницы |
| `--paper` | `#fbf8f1` | `#262320` | лист: зона загрузки, отчёт, текст работы |
| `--graphite` | `#2a2826` | `#ece5d7` | основной текст (не чистый чёрный) |
| `--graphite-soft` | `#5d5953` | `#b2a999` | подписи; он же «совет» |
| `--pencil` | `#b3261e` | `#f08a7e` | красный карандаш — **ошибка** |
| `--ochre` | `#855a00` | `#e3b456` | охра — **замечание** |
| `--ink` | `#23508f` | `#9fbcec` | синие чернила — кнопки, ссылки, фокус; **единственный акцент** |

- Серьёзность как у корректора, а не светофор: красный карандаш, охра, графит. Цвет никогда не единственный признак: рядом всегда слово («ошибка», «замечание») или знак.
- Тёмная тема — «лист под настольной лампой»: тёплый тёмно-серый, смысл цветов тот же.
- Контраст текста не ниже 4,5 : 1 (WCAG AA) на бумаге и на столе в обеих темах; это проверяет axe в e2e-тестах.

## Шрифты

- **PT Serif** — заголовки и текст работы: голос документа.
- **PT Sans** — интерфейс: голос инструмента.
- **PT Mono** — числа и единицы (мм, номера правил, оценка, счётчики): цифры одной ширины, столбцы не прыгают.

Все три — гарнитуры ParaType с полноценной кириллицей, лицензия SIL OFL 1.1. Файлы лежат в проекте (`src/ui/fonts`, только кириллица и латиница), внешних запросов нет — CSP и офлайн-режим работают как раньше. Три начертания PT Serif для первого экрана подгружаются заранее (`<link rel="preload">` в `index.html`), остальные — по мере нужды.

Шкала — пять ступеней: 13, 16, 20, 28 и 40 px; межстрочный интервал текста 1,5. На самом сайте соблюдаем ту же типографику, которую он проверяет: кавычки «», тире —, неразрывный пробел перед «мм».

## Движение

Анимация объясняет смену состояния, а не украшает:

| Что | Как |
|---|---|
| Перетаскивают файл | лист приподнимается на 2–4 px, тень глубже |
| Идёт проверка | по листу ходит линия сканирования; в конце доходит до низа и гаснет |
| Готов отчёт | блоки появляются один раз, по очереди с шагом 35 мс, всего не дольше 600 мс |
| Оценка и счётчики | «докручиваются» до значения за 600 мс (и при изменении — от прежнего) |
| Раскрыли «Почему это важно», «Показать все места» | содержимое проявляется и чуть съезжает |
| «Показать в тексте» | плавная прокрутка, абзац коротко подсвечивается |

Правила: только `transform` и `opacity`; 120–240 мс для интерфейса, до 600 мс для появления отчёта; одна кривая `cubic-bezier(.2,.7,.2,1)` на весь сайт; без библиотек — CSS и Web Animations API (`src/ui/motion.ts`). При `prefers-reduced-motion` сдвигов нет, остаётся только смена прозрачности.

Два честных компромисса:

- **Линия сканирования не показывает проценты.** Ядро проверки не сообщает, какая доля правил пройдена, а менять ядро ради анимации мы не стали. Поэтому линия ровно ходит по листу, пока идёт проверка, — без ложных процентов.
- **Раскрытие — без анимации высоты.** Высота блока меняется сразу, а содержимое проявляется (opacity + transform): анимация высоты заставляет браузер пересчитывать раскладку на каждом кадре.

## Чего здесь нет специально

- градиентов (фиолетовый → синий), градиентного текста, «светящихся» кнопок;
- стекла (`backdrop-filter: blur`) и размытых цветных пятен на фоне;
- эмодзи, «искорок» и слов «магия», «умный», «AI-powered»;
- Inter или одного системного шрифта на всё;
- центрированного «героя» с огромным заголовком и двумя кнопками;
- трёх одинаковых карточек «преимуществ» с иконками;
- больших скруглений и мягких теней на всём, бейджей-пилюль — скругления не больше 3 px, тень есть только у листа;
- появления каждого блока при прокрутке;
- цветов без смысла.

## Цифры (2026-10-25)

- CSS + JS: было 397 кБ, стало 408 кБ (+2,7 %). Шрифты — отдельно, около 380 кБ на все начертания, браузер качает только нужные.
- Lighthouse, мобильный профиль, собранная версия: производительность 90–98 (медиана трёх запусков 97), доступность 100. Без предзагрузки шрифтов было 89–92.

# Дизайн «Нормоконтроля»

Коротко о том, откуда взялся внешний вид и по каким правилам он сделан. Все числа (цвета, шрифты, размеры, длительности) живут в одном файле — `src/ui/tokens.css`. Снимки всех состояний: `npm run design:shots` → `docs/design/`.

## Образ

Сайт — школьная доска, на которой лежат белые листы. Страница целиком зелёная, как доска в классе; всё, с чем работают, — листы бумаги на ней. Отсюда всё остальное:

- **Зона загрузки** — лист A4 (210 × 297) с размеченными полями. Размерные линии и подписи «30 мм» начерчены «мелом» прямо на доске. Числа берутся из выбранных требований (правила PG-02…PG-05), поэтому при смене профиля лист меняется.
- **Отчёт** — большой белый лист. В каждом замечании слева серьёзность словом («ошибка», «замечание», «совет») и номер правила, справа текст. Блоки разделены тонкими линиями: это один документ, а не набор коробок.
- **Текст работы** — второй лист. Только он набран шрифтом с засечками (как сама работа в Word) и имеет красную линию полей, как в тетради; полоса у абзаца — пометка «здесь замечание».
- **Карта документа** — узкая полоска бумаги рядом с отчётом: штрих на каждый абзац, пропуски на месте пустых абзацев, засечки там, где замечания.
- **Ошибка чтения файла** — лист перечёркнут красной ручкой, а сообщение написано на отдельном листке. **Замечаний нет** — чистый листок.

Название «Нормоконтроль» набрано очень крупно и плотно — это единственное «громкое» место страницы, всё остальное спокойное.

## Цвет

| Токен | Светлая | Тёмная | Смысл |
|---|---|---|---|
| `--desk` | `#1f5a45` | `#12231c` | доска, фон страницы |
| `--on-desk` | `#f4f8f3` | `#eaf2ec` | текст и линии «мелом» на доске |
| `--paper` | `#ffffff` | `#1d2f28` | лист: зона загрузки, отчёт, текст работы |
| `--graphite` | `#16211b` | `#e8efe9` | основной текст на листе |
| `--graphite-soft` | `#55635a` | `#a9bdb0` | подписи; он же «совет» |
| `--pencil` | `#c2261b` | `#ff9a8d` | красная ручка учителя — **ошибка** |
| `--ochre` | `#855800` | `#ecc063` | охра — **замечание** |
| `--ink` | `#1b6146` | `#8ed6b1` | кнопки, ссылки и фокус на листе — тот же зелёный |

- Отдельного «фирменного» цвета нет: акцент — это сам цвет доски. На доске главная кнопка белая, на листе — зелёная.
- Красный, охра и серый означают только серьёзность и больше нигде не используются. Цвет никогда не единственный признак: рядом всегда слово.
- Тёмная тема — та же доска вечером: глубокий зелёный, листы темнее, смысл цветов тот же.
- Контраст текста не ниже 4,5 : 1 (WCAG AA) на доске и на листе в обеих темах (самое слабое сочетание — 5,6 : 1); это проверяет axe в e2e-тестах.

Как это устроено в коде: в `tokens.css` есть переменные «текущей поверхности» (`--fg`, `--line`, `--accent`…). По умолчанию они равны значениям для доски, а внутри листов (`.report`, `.preview` и др.) — значениям для бумаги. Кнопке не нужно знать, где она лежит.

## Шрифты

- **Golos Text** — весь интерфейс и заголовки. Современный гротеск ParaType, сделанный в первую очередь для кириллицы. Шрифт вариативный: один файл на все насыщенности от 400 до 900.
- **PT Serif** — только текст самой работы в предпросмотре: так сразу видно, где «голос программы», а где «голос документа».

Моноширинного шрифта нет: числа выровнены цифрами одной ширины (`font-variant-numeric: tabular-nums`). Курсива нет.

Оба шрифта — лицензия SIL OFL 1.1, файлы лежат в проекте (`src/ui/fonts`, только кириллица и латиница), внешних запросов нет. Два файла Golos Text подгружаются заранее (`<link rel="preload">` в `index.html`), PT Serif — когда появляется текст работы.

Шкала — пять ступеней: 14, 16, 20, 30 px и название 44–76 px (растёт с шириной окна). На самом сайте соблюдаем ту же типографику, которую он проверяет: кавычки «», тире —, неразрывный пробел перед «мм».

## Форма

- Скругление зависит от того, что это: лист бумаги — 2 px, кнопка и поле — 8 px, большая панель — 14 px.
- Мягких теней нет вообще. Единственная тень — жёсткая, без размытия: она появляется, когда файл перетаскивают и лист «приподнимается» над доской.

## Движение

Анимация объясняет смену состояния, а не украшает:

| Что | Как |
|---|---|
| Перетаскивают файл | лист сдвигается вверх-влево, под ним появляется жёсткая тень |
| Идёт проверка | по листу ходит линия сканирования; в конце доходит до низа и гаснет |
| Готов отчёт | блоки появляются один раз, по очереди с шагом 35 мс, всего не дольше 600 мс |
| Оценка и счётчики | «докручиваются» до значения за 600 мс (и при изменении — от прежнего) |
| Раскрыли «Почему это важно», «Показать все места» | содержимое проявляется и чуть съезжает |
| «Показать в тексте» | плавная прокрутка, абзац коротко подсвечивается |

Правила: только `transform` и `opacity` (и жёсткая тень листа); 180 мс для интерфейса, до 600 мс для появления отчёта; одна кривая `cubic-bezier(.2,.7,.2,1)` на весь сайт; без библиотек — CSS и Web Animations API (`src/ui/motion.ts`). При `prefers-reduced-motion` сдвигов нет, остаётся только смена прозрачности.

Два честных компромисса:

- **Линия сканирования не показывает проценты.** Ядро проверки не сообщает, какая доля правил пройдена, а менять ядро ради анимации мы не стали.
- **Раскрытие — без анимации высоты.** Высота блока меняется сразу, а содержимое проявляется: анимация высоты заставляет браузер пересчитывать раскладку на каждом кадре.

## Как мы уходили от «дизайна, сделанного нейросетью»

Сайты, которые оформляет ИИ, похожи друг на друга: у них есть набор привычек, по которым их узнают с первого взгляда. Перед переделкой мы собрали эти привычки (источники ниже) и проверили по списку и новый дизайн, и старый.

Оказалось, что **прежний вариант** («стол корректора»: кремовый фон, шрифт с засечками в заголовках, красный акцент, тонкие линии без скруглений, моноширинный шрифт для мелких подписей, цветная полоса сбоку у карточек) сам совпадал с одним из типичных наборов. Поэтому образ заменён целиком.

| Привычка ИИ | Что у нас |
|---|---|
| Inter, Roboto или системный шрифт на всё | Golos Text — выбран под кириллицу |
| Фиолетово-синие градиенты, градиентный текст, свечение | градиентов-украшений нет; цвета плоские |
| Тёмный фон с одним «кислотным» акцентом | акцента как отдельного цвета нет |
| Кремовый фон + засечки + терракотовый акцент | зелёная доска и чисто-белые листы |
| «Газетная» вёрстка: волосяные линии, нулевые скругления | скругление по смыслу: 2 / 8 / 14 px |
| Стекло (`backdrop-filter`), размытые пятна | нет |
| Центрированный «герой» с двумя кнопками и три одинаковые карточки с иконками | первый экран — сам инструмент: лист и выбор требований |
| Одинаковое скругление и одна мягкая серая тень на всём | мягких теней нет |
| Цветная полоса слева у карточки | серьёзность названа словом |
| Подписи ЗАГЛАВНЫМИ с разрядкой над каждым заголовком | нет; обычный регистр |
| Моноширинный шрифт для мелких подписей | нет; табличные цифры |
| Нумерация 01 / 02 / 03, «A · B · C», стрелка «→» в ссылках | нет |
| Эмодзи вместо иконок, слова «магия», «умный» | нет |
| Каждый блок выезжает при прокрутке | отчёт появляется один раз |

Что осталось и почему это не «привычка»: красная линия полей и полоса у абзаца в тексте работы — они несут информацию (где замечание), а не украшают.

## Цифры (2026-11-10)

- CSS + JS: 407 кБ (до первого редизайна было 397 кБ, +2,6 %). Шрифты — отдельно: было около 380 кБ, стало 166 кБ на шесть файлов; браузер качает только нужные.
- Lighthouse, мобильный профиль, собранная версия, три запуска: производительность 99–100, доступность 100.
